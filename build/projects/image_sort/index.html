Image sorting

Date: 2025-06-07T12:00:00Z

This is a really weird project idea I came upon on Youtube of someone sorting an image's pixels by their *(r, g, b)* values and I desperately wanted to recreate that. The visuals need a lot of attention (◞‸◟)💧

The project is currently hosted on a free cloudflare page: https://imgsortie.pages.dev/ It's a completely static website with the logic written in pure JS.

As of writing, only the whole image or horizontal lines work with some really confusing mask options. I really hope I'll get back to finishing this and expanding more on the idea.
