## How Create works

Create uses minecraft Entities to make awesome moving and interactive crafts called [contraptions](https://create.fandom.com/wiki/Contraption). As opposed to static, solid blocks, entities are a lot more dynamic, and a lot more complicated. Every mob, enemy, villagers, arrows, even items on the ground are all entities. These have a lot more restrictions as to how they can interact with the world, and these show in create contraptions. 

![create contraption spinning around](https://static.wikia.nocookie.net/create_mod/images/d/df/Ferris_Wheel_Mechanic_2.gif)
*source: https://create.fandom.com/wiki/Contraption*

Create uses these contraptions to free itself from the minecraft grid, allowing to build any kind of structure from solid blocks, and move them at very specific angles.

## Limits of contraptions

As the contraption's blocks are not solid, they hardly interact with the solid minecraft world. Create exposes a lot of special blocks, which still have functionality on contraptions, for example functional doors, seats, drills, etc. For our need, we only need a big disk spinning in a circle, and a [mechanical bearing](https://create.fandom.com/wiki/Mechanical_Bearing) does exactly that.
